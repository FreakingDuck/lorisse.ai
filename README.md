# lorisse.ai

The pages of lorisse.ai. Plain HTML, no build step, no network call from a page.

A push to `main` publishes: the host deploys this repository into the web root.

The site is in French only for now.

- `index.html`: the home page.
- `install/`: how to install the plugin.
- `fr/`: two pages that send an old `/fr/` address to the page at the root.
- `style.css`: the one stylesheet of every page.

The plugin itself lives in `lorisse-plugin`.
