Install Lorisse

Five minutes. Nothing is installed outside the Claude app, and it is removed in one click.

Before you start

You need the Claude desktop app with Cowork, or Claude Code. Lorisse's tool is a small program that runs on your own machine: Cowork and Claude Code start it; a plain chat does not.

Windows. Tried on Windows 11, in Claude Code.

Mac. Written from the documentation; not yet tried on a Mac. The program is built for both Apple chips and Intel. If macOS asks whether to allow it, say yes once.

In the Claude desktop app

  1. Open Customize, then Plugins.
  2. Choose Add, then Add marketplace, and type FreakingDuck/lorisse-plugin.
  3. Find Lorisse in the list and install it.
  4. Start a Cowork task on any folder and type: "Hello Lorisse, where are you?"

In Claude Code

The VS Code panel or a terminal.

  1. Type /plugins in the VS Code panel, or /plugin in a terminal.
  2. Under Marketplaces, add FreakingDuck/lorisse-plugin. In a terminal you can also type /plugin marketplace add FreakingDuck/lorisse-plugin.
  3. Under Plugins (Discover in a terminal), pick lorisse, Install, "Install for you".
  4. Type: "Hello Lorisse, where are you?" and allow the tool when asked.

What you should see

One line: Lorisse is here, and the folder it was started in. That is all it does today; it reads nothing and writes nothing.

If nothing answers

  • The plugin shows as installed and enabled.
  • You are in Cowork or Claude Code, not a plain chat.
  • Restart the app once.

When a new version comes

In the Claude desktop app

  1. Open Customize, then Plugins.
  2. On Lorisse's marketplace, choose Check for updates.
  3. Start a new Cowork task: it uses the new version.

To get new versions without asking, turn on Sync automatically on the same marketplace.

In Claude Code

  1. In a terminal, type /plugin and go to the Installed tab.
  2. Open lorisse and choose Update now.
  3. If Claude Code asks for it, type /reload-plugins, or simply start Claude Code again.

To get new versions on their own, open the Marketplaces tab, select Lorisse's marketplace and turn on auto-update. It is off by default for a marketplace that is not Anthropic's.

To remove it

The same screen. In the desktop app, open Lorisse, open its menu and choose Remove. In Claude Code, on the Installed tab, choose Uninstall.
