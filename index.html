Lorisse

A memory that is yours, in files you can read.

Install Lorisse →

Lorisse is a plugin for the Claude app. You talk; it files what matters (a decision, a thing to do, a person) as plain files in a folder on your own machine, and finds them again when you ask.

The Claude app already brings the models, the mail, the calendar and the web. Lorisse adds what is missing: a memory with rules. One fact, one file. Every change is one step you can undo. Nothing is ever deleted.

Where it stands

Today is the first version: it proves the way in. One tool, which answers when you say hello. The filing tools come next, one small step at a time; this page will say so when they do.
