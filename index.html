Lorisse

Une mémoire qui est à vous, dans des fichiers que vous pouvez lire.

Installer Lorisse →

Lorisse est un plugin pour l'application Claude. Vous parlez ; Lorisse range ce qui compte (une décision, une chose à faire, une personne) dans de simples fichiers, dans un dossier de votre machine, et les retrouve quand vous le demandez.

L'application Claude apporte déjà les modèles, le courrier, l'agenda et le web. Lorisse ajoute ce qui manque : une mémoire avec des règles. Un fait, un fichier. Chaque changement est un pas que vous pouvez défaire. Rien n'est jamais supprimé.

Lorisse arrive pas à pas : aujourd'hui, la première version vous répond quand vous dites bonjour. La mémoire suit.

Dans l'application Claude pour Mac :

  1. Ouvrez Customize, puis Plugins.
  2. Choisissez Add, puis Add marketplace, et tapez FreakingDuck/lorisse-plugin.
  3. Trouvez Lorisse dans la liste et installez le plugin.
  4. Lancez une tâche Cowork et tapez « Bonjour Lorisse, où es-tu ? ».

Lorisse vous répond, et vous dit dans quel dossier vous êtes.

Fait avec l'IA, à lire comme tel. Rien ici n'est garanti ; ce que cela fait sur votre machine vous appartient.
