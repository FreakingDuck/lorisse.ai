Installer Lorisse

Cinq minutes. Rien n'est installé en dehors de l'application Claude, et tout s'enlève en un clic.

Avant de commencer

Il vous faut l'application de bureau Claude avec Cowork, ou bien Claude Code. L'outil de Lorisse est un petit programme qui tourne sur votre propre machine : Cowork et Claude Code le lancent, une simple conversation ne le lance pas.

Windows. Essayé sur Windows 11, dans Claude Code.

Mac. Écrit d'après la documentation ; pas encore essayé sur un Mac. Le programme est prévu pour les puces Apple comme pour Intel. Si macOS demande s'il faut l'autoriser, répondez oui, une fois.

Dans l'application de bureau Claude

  1. Ouvrez Customize, puis Plugins.
  2. Choisissez Add, puis Add marketplace, et tapez FreakingDuck/lorisse-plugin.
  3. Trouvez Lorisse dans la liste et installez le plugin.
  4. Lancez une tâche Cowork sur n'importe quel dossier et tapez « Hello Lorisse, where are you? » ou « Bonjour Lorisse, où es-tu ? ».

Dans Claude Code

Le panneau de VS Code ou un terminal.

  1. Tapez /plugins dans le panneau de VS Code, ou /plugin dans un terminal.
  2. Sous Marketplaces, ajoutez FreakingDuck/lorisse-plugin. Dans un terminal, vous pouvez aussi taper /plugin marketplace add FreakingDuck/lorisse-plugin.
  3. Sous Plugins (Discover dans un terminal), choisissez lorisse, puis Install, puis « Install for you ».
  4. Tapez « Hello Lorisse, where are you? » ou « Bonjour Lorisse, où es-tu ? », puis autorisez l'outil quand Claude vous le demande.

Les menus sont cités en anglais ; dans une application en français, leurs noms peuvent différer.

Ce que vous devriez voir

Une ligne : Lorisse est là, avec le dossier où la tâche a été lancée. C'est tout ce que fait Lorisse aujourd'hui : rien n'est lu, rien n'est écrit.

Si rien ne répond

  • Le plugin apparaît comme installé et activé.
  • Vous êtes dans Cowork ou dans Claude Code, pas dans une simple conversation.
  • Redémarrez l'application une fois.

Pour l'enlever

Le même écran. Dans l'application de bureau, ouvrez Lorisse, ouvrez son menu et choisissez Remove. Dans Claude Code, sur l'onglet Installed, choisissez Uninstall.
